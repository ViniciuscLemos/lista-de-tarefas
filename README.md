# 📝 Lista de Tarefas

Aplicação de lista de tarefas no terminal feita em Python.

## Funcionalidades

- Adicionar tarefas
- Listar todas as tarefas
- Marcar tarefa como concluída
- Remover tarefa
- Salva os dados automaticamente em arquivo JSON

## Como usar

**1. Clone o repositório**
```bash
git clone https://github.com/ViniciuscLemos/lista-de-tarefas
cd lista-de-tarefas
```

**2. Execute o programa**
```bash
python todo.py
```

Não precisa instalar nenhuma dependência — só Python 3 já basta.

## Tecnologias

- Python 3
- JSON (para salvar os dados)
